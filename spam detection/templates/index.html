Developer REST API Reference

Integrate SpamGuard AI directly into your Python scripts, postfix/sendmail filters, webhooks, or CRM pipelines.

POST /api/predict

Classify single email text or subject/body pair with full explainability payload.

curl -X POST "http://localhost:8000/api/predict" \
     -H "Content-Type: application/json" \
     -d '{
       "subject": "Urgent: Verify Your Account",
       "body": "Your account has been suspended. Click here to verify password."
     }'
import requests

url = "http://localhost:8000/api/predict"
payload = {
    "subject": "URGENT: Microsoft 365 Password Expiration",
    "body": "Action Required: Your password expires in 2 hours. Update immediately."
}

response = requests.post(url, json=payload)
data = response.json()
print("Verdict:", data["verdict"])
print("Spam Probability:", data["spam_probability"])
print("Threat Flags:", data["heuristics"]["threat_flags"])
const res = await fetch("http://localhost:8000/api/predict", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    subject: "Action Required",
    body: "Please confirm your wire transfer details."
  })
});
const data = await res.json();
console.log(data.verdict, data.spam_probability);

Easiest method. Zero server maintenance, free SSL HTTPS certificate, and automated GitHub deploys.

• Start Command: uvicorn app:app --host 0.0.0.0 --port 10000

Linux Server Deployment Cheatsheet

# 1. Clone repository to server
git clone https://github.com/your-username/spam-detection.git /var/www/spamguard
cd /var/www/spamguard

# 2. Set up Python virtual environment
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. Test running the app
uvicorn app:app --host 0.0.0.0 --port 8000

# 4. Run continuously as a background Systemd Service (/etc/systemd/system/spamguard.service)
[Unit]
Description=SpamGuard AI Service
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/var/www/spamguard
ExecStart=/var/www/spamguard/venv/bin/uvicorn app:app --host 127.0.0.1 --port 8000 --workers 4
Restart=always

[Install]
WantedBy=multi-user.target
